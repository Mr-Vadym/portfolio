# Frontend Portfolio

Personal portfolio website for an HTML, CSS, and JavaScript developer.

## Tech Stack

- React
- vinext
- Vite
- JavaScript / JSX
- CSS
- lucide-react

## Features

- Responsive portfolio layout
- Developer portrait placeholder
- Project screenshot placeholders
- Services, projects, skills, and contact sections
- Mobile navigation
- Production build support

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Images

Replace the placeholder assets in `public/images/` with your own portrait and project screenshots.
